## 🌟 核心价值与特色

- 📖 **Zed 风格分栏伴读**：右侧专注阅读 Markdown 原文，左侧与 AI 进行针对性探讨，提问时绝不打乱当前阅读位置。
- ✨ **选区多维伴读预设**：划选文字即刻触发 `[✨ 解释]`、`[💡 通俗类比]`、`[🔍 深度推导]`、`[⚡ 代码评审]` 与 `[➕ 加入提问]`，一键直击不同深度。
- 🔁 **AI 回答二次追问（Recursive Clarification）**：阅读左侧 AI 回答时，遇到生僻概念划词也能弹出 `[追问此概念]`，层层递进彻底读懂。
- 📑 **浮动大纲（TOC）与章节联动**：右侧支持一键展开多层级目录抽屉，阅读滚动时实时联动高亮当前小节，支持快速检索与跳跃。
- 🔍 **文档内快捷查找（Cmd+F / Ctrl+F）**：轻量快捷搜索，匹配项实时高亮、快速上一个/下一个遍历与回车跳转。
- 📐 **KaTeX 公式与 Mermaid 架构图**：
  - 完整支持行内 `$E=mc^2$` 与独立块数学公式排版；
  - 动态按需加载 Mermaid 流程图/时序图，并支持一键切换“图表/源码”视图。
- 🌙 **深色模式（Dark Mode）**：支持一键切换跟随系统偏好、浅色模式或 Zed/Obsidian 质感深灰暗色主题。
- 🧭 **章节追踪与段落上下文**：自动反查划选内容所属的标题层级（例如 `# 第一章 > ## 1.2 架构`）并提取邻近段落，AI 回答应答更具针对性。
- 👁️ **透明预算与防截断预警**：
  - 实时 Token 消耗与预算进度条，拒绝把 AI 当黑盒。
  - “发送内容预览”多段式透视 Prompt（系统指令 / 选区 / 历史）。
  - 超出预算时主动告警，杜绝“静默截断后声称理解全文”，支持改发“当前阅读章节”。
- 🎯 **引用反向定位高亮（Reverse Locator）**：点击左侧聊天记录中的引用卡片，右侧文档平滑滚动并居中脉冲高亮原文，便于比对验证。
- 💾 **精确阅读位置记忆与多文档会话**：
  - 毫秒级像素级（scrollTop）阅读进度记忆，切换文档重载瞬间恢复。
  - 最近阅读文档列表下拉切换，每个文档绑定独立的 AI 会话记录。
- 📥 **问答笔记一键导出**：一键将当前的问答对话沉淀导出为排版优雅的 Markdown 文件（含引用与章节元信息）。
- 🔄 **单条回答 `[换模型重答]`**：每条 AI 回答气泡底部均可一键选择已保存的其他模型重新回答，克制而优雅地实现不同模型的深度对比。
- 🛡️ **首次外发域名隐私提示**：遵循规划书 7.2 安全红线，首次向某个外部服务发起提问时主动展示目标域名与发送说明，支持一键信任。
- 🔌 **全兼容 OpenAI 接口协议**：内置 DeepSeek、OpenAI、本地 Ollama（免 Key）一键预设，支持保存多套模型配置。
- 🦊 **全矢量灵动低干扰吉祥物**：
  - **动态尾巴姿态**：根据当前文档阅读深度（0%~100%），尾巴由收拢逐步优雅抬起舒展。
  - **耳朵状态映射**：未配置（放松）、准备就绪（竖耳）、思考等待（微动）、回答生成（专注）、异常（放低）。
  - **阅读光环与零位图失真**：全矢量 SVG 原生渲染，头像外圈圆环跟随阅读百分比实时旋转舒展。
  - **减少动画开关（Reduce Motion）**：支持跟随系统偏好或手动开启，专为极简与低能耗打造。
- 💻 **多语言代码块高亮**：Prism.js 深度定制深色代码块，附带语言徽章与一键复制反馈。
- 🧪 **自动化质量测试网**：内置 `npm test` 自动化测试套件，全面覆盖 TOC 大纲解析、文档 ID 哈希、视口截取算法与存储适配。

## 🛠 技术架构

| 层次 | 选型 | 说明 |
|---|---|---|
| **桌面底座** | Tauri 2 (Rust 2024 edition) | 轻量极速原生沙箱，跨平台文件与安全协议 |
| **前端框架** | React 18 + TypeScript | 强类型开发与组件化 |
| **样式体系** | Tailwind CSS | 现代原子化极简高质感设计 |
| **Markdown 渲染** | react-markdown + remark-gfm | 标准 GFM、表格与扩展语法 |
| **数学公式与图表** | KaTeX + Mermaid | 行内/独立公式排版与按需加载时序/流程图 |
| **代码高亮** | Prism.js | 多主流语言深度高亮与一键复制 |
| **状态管理** | Zustand | 极简多模块响应式状态流 |
| **通信协议** | 原生 SSE + Tauri HTTP 插件 | 原生绕过 CORS 限制，流式打字与手动中断 |
| **持久化存储** | StorageService (IndexedDB + localStorage) | 异步抽象适配层，支持长文档与多会话隔离 |

## 🚀 本地极速运行

```bash
# 1. 克隆仓库
git clone https://github.com/yourwayai/fox.git
cd fox

# 2. 安装依赖
npm install

# 3. 启动 Web 开发服务器（秒级热更新，免 Rust/Xcode 本地依赖）
npm run dev

# 4. 启动原生桌面应用（Tauri 2 桌面端开发环境）
npm run tauri:dev

# 5. 打包桌面端原生应用安装包
npm run tauri:build
```
